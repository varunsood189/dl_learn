# How to use this library

This repository is a curated reference library for deep learning and NLP resources.

## Reading paths

1. **New to deep learning**
   - Start with `topics/foundations.md`, then `topics/optimization.md`.
2. **NLP-focused readers**
   - Start with `topics/nlp.md`, then `topics/transformers.md`.
3. **Transformer deep dive**
   - Start with `topics/transformers.md`, then cross-reference `topics/nlp.md`.

## How to navigate topic files

Each entry includes:
- Resource metadata (type, level, time)
- Why the resource was selected
- Key ideas and prerequisites
- Related resources for next-step reading

## Curation principles

- Quality over quantity: include high-signal, canonical references.
- Every entry must answer "why this resource?"
- Avoid duplicates unless perspective is substantially different.
- Keep resources up to date and remove stale links.
