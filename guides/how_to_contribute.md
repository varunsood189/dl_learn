# How to contribute

Thanks for helping improve this curated library.

## Add a new resource

1. Pick the most relevant file under `topics/`.
2. Copy the format from `templates/resource_entry.md`.
3. Fill all metadata fields.
4. Add a short, concrete "Why it's included" section.
5. Link at least one related resource.

## Curation checklist

- Is this a high-signal reference?
- Is the audience level accurate?
- Are prerequisites clear?
- Does it overlap heavily with an existing entry?
- Are links working?

## Style guide

- Keep descriptions concise and specific.
- Prefer bullet points for key ideas.
- Use consistent title capitalization.
